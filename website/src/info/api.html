API

Access Overwatch esports statistics for players, teams, maps, tournaments, matches, and comparisons.

Base URL

http://owcslab.co.uk

Homepage

GET /api/home

Returns match totals, player-stat totals, and the latest matches.

Players

GET /api/players
GET /api/players/filters
GET /api/players/:name

The player list accepts filters for tournaments, stages, regions, teams, roles, and circuits. Player detail requests also support tournament filters.

Teams

GET /api/teams
GET /api/teams/:name
GET /api/compare/teams

Use circuit=owcs, circuit=owwc, or circuit=all with the team list endpoint.

Maps

GET /api/maps
GET /api/maps/:name

Map detail responses include ban statistics and team win-rate data.

Tournaments

GET /api/tournaments

Results can be scoped with player, playerId, team, teamId, or map.

Team comparison

GET /api/compare?teamA=12&teamB=34

Returns head-to-head results, match history, team totals, map comparisons, and ban statistics. Optional filters use tournaments and tournamentMode.

Examples

GET /api/players?role=Support&region=EMEA
GET /api/teams?circuit=owcs
GET /api/tournaments?teamId=12
GET /api/compare?teamA=12&teamB=34&tournaments=5,9&tournamentMode=include

Successful requests return JSON. Errors return a JSON object with an error message and an appropriate HTTP status code.
