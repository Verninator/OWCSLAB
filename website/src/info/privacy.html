Privacy Policy

Last Updated: August 2026

1. INTRODUCTION & SCOPE

This website serves as an informational platform. We operate a streamlined environment optimized for visitor privacy. This website does not feature user accounts, registration portals, interactive login options, contact forms, or marketing tracker networks. We do not actively request, process, or store personal consumer records or identity markers.

2. SUBPROCESSORS & HOSTING INFRASTRUCTURE

To distribute and sustain our digital services globally, we partner with specialized enterprise infrastructure networks. These entities function as third-party Data Processors under international privacy frameworks:

  • Infrastructure Host: Google Cloud Platform (Google App Engine) Our primary codebase and server environment run on Google App Engine. This platform serves public network content and handles initial traffic routing.
  • Content Storage Host: Microsoft Azure Cloud Our website content is systematically retrieved from an isolated Microsoft Azure database. This database stores internal site architecture and editorial materials only. It does not ingest, hold, or compile any user records, visitor logs, or behavioral tracking files.

3. AUTOMATIC DATA PROCESSING & SERVICE LOGS

When browsing this website, our hosting framework (Google App Engine) automatically processes standard networking parameters. This occurs strictly to sustain secure, high-performance data transfers. This information includes:

  • Internet Protocol (IP) addresses (utilized for firewall validation and DDoS shielding).
  • Browser and configuration metadata (User-Agent string, active language settings, operating system).
  • Structural transaction records (Access timestamps, requested target pathways, transferred payload volumes).


Purpose of Processing: This standard operational data is used exclusively to debug system errors, optimize network infrastructure, and stop malicious network attacks. Data Retention & Lifespan: Server-side system metadata is routinely kept for up to 180 days before being automatically purged by our infrastructure providers.

4. COOKIES & TRACKING NETWORKS

We do not use tracking cookies, advertising metrics, behavior recorders, or marketing pixels. Any cookie generated during your visit is classified as strictly necessary. These are temporary infrastructure cookies automatically deployed by Google App Engine to manage server traffic balances (session affinity). They expire immediately when your browser session concludes.

5. GLOBAL COMPLIANCE & TRANSFERS

Our platform serves an international audience. Infrastructure operations by Google Cloud and Microsoft Azure adhere to rigorous security frameworks, including standard Data Processing Addendums (DPA) and Standard Contractual Clauses (SCCs). These mechanisms guarantee safe, regulated data processing across global boundaries.
